# Applied projects

These projects use the concepts from the foundation notebooks in a complete workflow. They are kept separate from the ordered lessons because they combine several topics and include application-specific code.

| Project | Main connection to the foundations | What it adds |
|---|---|---|
| [Flower image classifier](flower_classifier/README.md) | [06 optimizers](../notebooks/06_optimizers.ipynb), [07 activation functions](../notebooks/07_activation_functions.ipynb), and [09 MLP from scratch](../notebooks/09_mlp_from_scratch.ipynb) | Image preprocessing, transfer learning, validation curves, top-k evaluation, checkpointing, and inference |

The project notebook is [flower_classifier.ipynb](flower_classifier/flower_classifier.ipynb). The dataset is downloaded manually using the link documented there and in the project README; no project code downloads it automatically.
