# Machine Learning Notes

This repository is a record of learning and implementing machine learning systems. It connects the mathematics behind a model to small, runnable experiments and then to larger PyTorch projects, with the aim of making each step understandable rather than treating the model as a black box.

The material follows that progression from basic numerical models and optimization through neural networks, computer vision, and language models. Explanations are kept alongside the experiments so that the results, assumptions, and limitations can be examined together.
